# Defold-Mangler

Irreversably mangles function names in Lua scripts prior to building; release only.

What's this for? Obfuscators don't touch function names.

To use: Add

```
https://github.com/p7r0x7/defold-mangler/archive/refs/tags/v<DEFOLD VERSION>.zip
```

to your dependencies in game.project. Notice mangler.config.
